# 工单投入及一览

## 1. 功能概述

“工单投入及一览”用于对工单的投产准备情况、计划投批情况、在制执行情况以及组件来料/退料情况进行集中查询和跟踪。

该页面的核心价值不是“维护工单”，而是帮助计划、生产、物料及现场管理人员快速判断某一工单当前是否具备投入条件、已经投入到什么程度、还差多少、是否存在来料与退料差异。

页面同时承担以下两类用途：

1. **工单查询看板**
   - 查询工单基础信息
   - 查询工单计划投产、计划交货、当前状态
   - 查看未分批数量、已计划数量、完成数量、在制数量、报废数量

2. **投入过程辅助操作入口**
   - 从“未分批数量”进入工单分批
   - 从“计划数量”进入计划投批明细
   - 在计划投批明细中执行“计划投批 / 取消计划”

## 2. 适用范围

### 2.1 适用业务场景

适用于工单从“已建立”到“正式投入生产”之间的查询与跟踪场景，尤其用于：

- 查询某工单是否还有可投入数量
- 查询某工单已经计划了多少批次
- 查询某工单的组件来料、IRA来料、组件退料与剩余数量
- 判断工单当前状态与生产进度是否一致
- 导出当前筛选条件下的工单清单用于线下分析

### 2.2 适用角色

- 计划员
- 生产管理员
- 物料管理员
- 车间现场管理人员
- 需要跟踪工单投入状态的工程/管理人员

## 3. 页面入口与组成

### 3.1 页面入口

工单管理 → 工单投入及一览

### 3.2 页面组成

页面由两部分组成：

#### 3.2.1 查询区

用于输入筛选条件，支持组合查询。

#### 3.2.2 列表区

用于分页展示符合条件的工单记录，并提供与投入相关的查看/跳转操作。

#### 3.2.3 计划投批明细弹窗

当点击“计划数量”列中的可点击数值时，弹出“计划投批信息”窗口，查看当前工单已计划或待处理的 lot 信息，并可执行计划投批/取消计划。

## 4. 查询条件说明

| 查询项 | 说明 | 备注 |
|---|---|---|
| 工单号 | 按工单号查询 | 支持可用工单搜索选择 |
| 产品分类 | 按产品分类筛选 | 会联动产品型号 |
| 产品型号 | 按产品型号筛选 | 数据来源受产品分类影响 |
| 生产地点 | 按生产地点筛选 | 下拉取值 |
| 工单类型 | 按工单类型筛选 | 例如量产、实验、返工等 |
| 晶圆属性 | 按晶圆属性筛选 | 下拉取值 |
| 计划投产日期-从 | 查询开始日期 | 与结束日期组成范围 |
| 计划投产日期-至 | 查询结束日期 | 与开始日期组成范围 |

### 4.1 查询规则

1. 支持多条件组合查询。
2. 点击“查看”后，从第一页开始加载结果。
3. 工单号、下拉框支持回车触发查询。
4. 点击“重置”后清空查询条件，同时清空当前列表数据。
5. 点击“导出”时，按照当前查询条件导出**全部符合条件的数据**，不是仅导出当前页。

## 6. 页面交互说明

### 6.1 查看

用户输入筛选条件后点击“查看”，系统调用查询接口加载工单数据，并在列表区分页展示。

### 6.2 重置

点击“重置”后：

- 清空查询表单
- 清空当前列表结果
- 不自动重新查询

### 6.3 导出

点击“导出”后：

1. 系统读取当前所有查询条件
2. 调用后端导出查询接口查询全部结果
3. 按页面列表列顺序组织导出内容
4. 对页面中经过 renderer 处理的列，导出时取其显示值
5. 生成 Excel 文件并下载

#### 6.3.1 导出特点

- 导出范围为当前筛选条件下的全部数据
- 不是仅导出当前分页的数据
- 导出列与页面显示列保持一致

### 6.4 未分批数量点击逻辑

当“未分批数量”存在值时，页面将其展示为可点击链接。

点击后：

- 打开工单分批窗口
- 传入当前工单号
- 用户在新窗口中完成分批操作
- 窗口关闭后自动刷新当前列表

### 6.5 计划数量点击逻辑

当“计划数量”存在值时，页面将其展示为可点击链接。

点击后：

- 打开“计划投批信息”弹窗
- 展示该工单下的计划 lot 明细
- 可查看 lot、产品、优先级、计划投产日期、状态、工序等信息

### 6.6 计划投批明细弹窗操作

弹窗中提供两个按钮：

#### 6.6.1 计划投批

- 需先勾选明细 lot
- 若未勾选，提示用户先选择批次
- 勾选后进入计划投批保存动作

#### 6.6.2 取消计划

- 需先勾选明细 lot
- 若未勾选，提示用户先选择批次
- 勾选后执行取消计划
- 成功后关闭弹窗并刷新主列表

## 7. 关键业务口径

这一部分是页面使用中最容易产生歧义的内容，必须统一说明。

### 7.1 未分批数量

未分批数量不是简单的“工单总数 - 完成数”。

系统会根据工单类别采用不同口径计算：

1. **测试类/特定分类工单**
   - 如工单号以 `T` 开头，或产品分类属于 FT、RW、COG、LCD_CP、SENSOR_CP、OIS、WLT 等时
   - 未分批数量置为 0
   - 原因：这些工单不按照普通逻辑进行未分批数量计算

2. **COM 类工单**
   - 按计划历史数量计算
   - 公式逻辑：`工单总数 - 已计划历史数量`

3. **其他常规工单**
   - 公式逻辑：
     `工单总数 - 完成数量 - 在制数量 - 报废数量 - 已计划数量`

### 7.2 计划数量

计划数量来源于该工单下的 lot plan 汇总，但不同产品分类口径不同：

- WLT：按批次数量统计
- SENSOR_CP / LCD_CP：按 lot 数量累加统计
- OIS：仅统计状态满足条件的 lot
- 其他：按 lot 的 qty 累加

因此，“计划数量”代表的是**当前已进入计划投批体系的数量**，不是已完成投入数量。

### 7.3 完成数量

完成数量为工单已完工的累计数量，用于衡量工单达成进度。

### 7.4 进行中数量

进行中数量为当前在制中的数量。若后端计算结果小于 0，页面统一按 0 展示，避免出现负数在制的异常显示。

## 8. 来料、退料、IRA、剩余数量口径

本页面中“IRA数量、来料数量、退料数量、剩余数量”主要用于补充展示 COM 类工单的物料状态。

### 8.1 适用范围

仅当工单产品分类为 **COM** 时，系统才补充计算并返回以下字段：

- IRA数量
- 来料数量
- 退料数量
- 剩余数量

非 COM 工单通常不展示该类补充数据口径。

### 8.2 IRA数量

IRA数量表示该工单已接收的 IRA 物料数量。

**统计口径：**
- 数据来源：`AM_RECEIVE`
- 条件：`STATUS = 'RECEIVED'`
- 条件：`PRODUCT_TYPE = 'IR'`

### 8.3 来料数量

来料数量表示该工单已关联的组件来料总量。

**统计口径：**
- 通过工单与组件物料关系进行汇总
- 统计 `RECEIVE_QTY`

该值用于反映工单已实际接收的组件数量。

### 8.4 退料数量

退料数量表示该工单已发生退料的组件数量。

**统计口径：**
- 数据来源：`AM_RECEIVE`
- 条件：`STATUS = 'RETURN'`
- 条件：`PRODUCT_TYPE = 'IR'`

该值用于反映原先已接收物料中，已退回的部分。

### 8.5 剩余数量

剩余数量表示当前工单关联组件中仍可用的剩余数量。

业务上，它用于辅助判断：

- 当前来料是否已经被消耗完
- 是否还有多余组件可继续支持投入
- 是否存在“来料很多但可用数量不足”这类异常情况

## 9. 异常与限制说明

### 9.1 无查询结果

当当前查询条件下无结果时，列表显示为空。

### 9.2 未选择 lot 执行计划操作

在计划投批明细弹窗中，若未选择任何 lot 就点击“计划投批”或“取消计划”，系统会提示先选择批次。

### 9.3 某些工单类型不支持未分批数量计算

对于测试类或特殊分类工单，未分批数量按 0 处理，这是系统既有规则，不代表数据异常。

### 9.4 OIS 类计划数量有额外过滤

OIS 类工单在统计计划 lot 时，需额外判断物料状态，不能直接按全部 lot plan 汇总。

## 10. 使用建议

1. 若要判断工单是否还能继续投入，建议结合查看：
   - 未分批数量
   - 计划数量
   - 剩余数量
   - 状态

2. 若要判断组件物料是否异常，建议结合查看：
   - 来料数量
   - 退料数量
   - 剩余数量
   - IRA数量

3. 若需线下比对或跨部门沟通，建议使用导出功能获取完整结果，而不是仅截图当前分页数据。
