# 取消 COM 真空包检PASS 操作
## 0. 可行性分

1. 取消 COM 真空包检PASS 操作，扫描为绿色则直接跳站，不需要点PASS
2. 就是现在的话想取消手动点pass 的动作，核对成功就直接跳到下一
3. 取消 QA 操作的话，有太多动作了，人力不足，看看能不能优化，现在就是需要专门一个人坐那

## 1. 逻辑实现

在grid.js，修改行的监听方法，满足条件自动执行`vacuumCheckVboxPass()`，不需要点击pass

```jsx
getRowClass: function(record, rowIndex, rowParams, store1) {
    var tboxId = Ext.getCmp('tBoxId').getValue();
    var itemId = record.data.boxId;
    if (!Ext.isEmpty(tboxId)) {
        tempArray.push(tboxId);
    }
    if (tempArray.length != 0) {
        for (var i = 0; i < tempArray.length; i++) {
            if (tempArray[i] == itemId) {
                unique(tempArray);
                if (store1.getCount() == tempArray.length) {
                    vacuumCheckVboxPass();
                } else {
                    return 'x-grid-record-green';
                }
            }
        }
    }
}
```
