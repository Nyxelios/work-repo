
## 三、核心框架与组件

### 3.1 Web 层

| 组件 | 说明 |
|------|------|
| **Struts 1.x** | MVC 框架，Action 处理请求 |
| **Ext.js** | 前端 UI 框架，表格/表单/图表 |
| **JSP** | 服务端页面渲染 |

**Action 标准模式**:
```java
public class XxxAction extends PrpSetupAction {
    public ActionForward perform(ActionMapping mapping, ActionForm form,
                                  HttpServletRequest request, HttpServletResponse response) {
        String action = request.getParameter("action");
        if ("create".equals(action)) return create(request, response);
        if ("update".equals(action)) return update(request, response);
        if ("read".equals(action))   return read(request, response);
        if ("delete".equals(action)) return delete(request, response);
        return mapping.findForward(Constants.MODIFY_KEY);
    }
}
```

### 3.2 业务层

| 组件 | 说明 |
|------|------|
| **Spring IoC** | Bean 管理，依赖注入 |
| **AppContext** | 获取 Spring Bean 的工具类 |
| **Quartz** | 定时任务调度（如 CpAutoPlanJob） |

### 3.3 数据层

| 组件 | 说明 |
|------|------|
| **JDBC Template** | Spring JDBC 封装 |
| **原生 SQL** | 复杂查询直接写 SQL |
| **Oracle** | 关系型数据库 |

## 五、定时任务

| 任务 | 类 | 说明 |
|------|-----|------|
| CP自动排料 | `CpAutoPlanJob.java` | CP产线自动排料工单 |
| COM工单关闭 | `ComAutoCloseJob.java` | 定时查询并关闭COM工单 |

## 六、构建与发布

```
SVN 源码 → Jenkins 构建 → Ant 打包 → WebLogic 部署
```

1. 从 SVN 拉取最新代码
2. Jenkins 触发 Ant 构建
3. 生成 WAR/EAR 包
4. 部署到 WebLogic Server
