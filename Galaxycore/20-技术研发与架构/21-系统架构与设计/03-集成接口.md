# Galaxycore MES 集成接口

## 一、集成全景

```text
ERP / 经营管理系统
  └─ 下发工单、计划、产品信息

WMS / 仓库系统
  └─ 提供晶圆、辅料、库存状态

SCADA / 设备系统
  └─ 提供设备状态、测试结果、过站数据

OA / 邮件系统
  └─ 提供流程校验、异常通知、业务提醒

                ↓
           MyCIM2 MES

- 工单接收与管理
- 晶圆与辅料管理
- 生产执行与过站
- 品质控制
- 包装与入库
- 数据追溯与异常处理
```

## 二、ERP 集成

### 2.1 工单同步

| 项目 | 说明 |
|------|------|
| 方向 | ERP → MES |
| 方式 | 数据库中间表 |
| 频率 | 实时或定时同步 |
| 核心表 | `ERP_WORKORDER` |

#### 典型流程
1. ERP 开立工单并写入中间表
2. MES 定时任务或人工操作同步工单
3. 数据写入 `WORKORDER`
4. 计划员在 MES 中接收并推进后续生产流程

#### 关键字段映射

| ERP 字段 | MES 字段 | 说明 |
|---------|---------|------|
| `WORKORDER_ID` | `WORKORDER_ID` | 工单号 |
| `PRODUCT_ID` | `PRODUCT_ID` | 产品型号 |
| `QTY` | `QTY` | 数量 |
| `PRODUCT_CLASSIFY` | `PRODUCT_CLASSIFY` | 产品分类 |

### 2.2 入库回传

| 项目 | 说明 |
|------|------|
| 方向 | MES → ERP |
| 方式 | 中间表或接口调用 |
| 触发 | MES 入库完成后 |
| 回传内容 | 工单、批次、数量、状态 |

## 三、WMS 集成

### 3.1 晶圆 / 辅料接收

| 项目 | 说明 |
|------|------|
| 方向 | WMS → MES |
| 方式 | 数据库同步 |
| 核心表 | `WMS_MMS_MATERIAL_LOT_UNIT`, `BACKEND_WAFER_RECEIVE` |

#### 典型流程
1. WMS 完成来料入库
2. 晶圆或辅料信息同步到 MES
3. MES 线边仓接收页面查询可用物料
4. 工单绑定时校验物料状态、等级与属性

### 3.2 晶圆状态同步

| 状态 | 说明 |
|------|------|
| `Create` | 已创建，未发料 |
| `Issue` | 已发料 |
| `In` | 已入站 / 已接收 |
| `Package` | 已包装 |

## 四、设备系统集成

### 4.1 设备数据采集

| 项目 | 说明 |
|------|------|
| 设备类型 | Prober、Handler、Tester |
| 采集方式 | 协议采集、文件解析或中间表 |
| 数据内容 | 测试结果、等级、状态、设备信息 |

### 4.2 过站触发逻辑

```text
设备完成测试
→ 上传测试数据
→ MES 解析结果
→ 执行过站或状态更新
→ 写入事务历史 / 履历表
```

## 五、邮件通知

| 场景 | 触发条件 | 接收对象 |
|------|---------|---------|
| 载具变更通知 | 载具信息变更 | 相关业务人员 |
| 工单异常通知 | 工单状态异常 | 计划 / 生产人员 |
| 系统告警 | 系统异常 | 运维人员 |

实现方式一般基于 Java Mail API 和 SMTP 配置。
相关实现可参考：[[实现邮箱发送]]

## 六、OA / 流程校验集成

| 项目 | 说明 |
|------|------|
| 用途 | OA 单号校验、特殊流程审批 |
| 场景 | 晶圆属性不匹配、例外放行、流程特批 |
| 典型规则 | FT / FT-AE 工单需要满足指定 OA 前缀规则 |

## 七、接口异常与监控

### 7.1 常见异常

| 异常 | 原因 | 处理方式 |
|------|------|---------|
| 工单同步失败 | ERP 中间表无数据或数据不完整 | 检查 ERP 下发情况与同步任务 |
| 晶圆状态不一致 | WMS 未及时同步 | 重新同步或人工核对 |
| 设备数据丢失 | 网络中断、采集异常 | 补传或检查日志 |
| 回传失败 | ERP / WMS 接口异常 | 检查接口状态与错误日志 |

### 7.2 监控建议

- 定时检查 `ERP_WORKORDER` 是否存在未同步数据
- 定时比对 `WMS_MMS_MATERIAL_LOT_UNIT` 与现场状态
- 监控设备采集日志与异常告警
- 对关键回传结果保留失败重试机制
