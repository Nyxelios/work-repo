# COM数量恢复

```sql
--COM数量修改
--1.根据批次号修改qty1的值
SELECT l.QTY1 ,l.INPUT_QTY1 ,l.* FROM LOT l WHERE l.LOT_ID ='A205-C041661.02-304-01';
--2.根据批次rrn，如果有等级数量，就修改qty和unpacked_qty的数量
SELECT w.QTY, w.UNPACKED_QTY, w.* FROM WIP_LOT_DIE_BIN w WHERE w.LOT_RRN ='311213641';
--3.查找工单号
SELECT le.OUTER_ORDER_NO ,le.* FROM LOT_EXT le WHERE le.LOT_RRN =311213641;
--4.根据工单号，修改wip_qty在线数量，scrap_qty报废数量，计划数量不变，qty1数量增加，在线数量增加，报废数量减少
SELECT w.WIP_QTY , w.SCRAP_QTY ,w.* FROM WORKORDER w WHERE w.WORKORDER_ID ='ZJZC230213005';
--5.根据批次rrn，修改reason_category是loss值的报废数量，增加或者减少，workorder表里的值也进行相应的修改
SELECT * FROM TRANS_REASON tr WHERE tr.INSTANCE_RRN =311213641;
SELECT w.WIP_QTY ,w.SCRAP_QTY ,w.* FROM WORKORDER_H  w WHERE w.WORKORDER_ID ='ZJZC230213005';
```
