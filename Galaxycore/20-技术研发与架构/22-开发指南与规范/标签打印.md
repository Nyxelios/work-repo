# FT打印配置新增打印标签

工艺规划下的FT配置管理的FT打印新增打印标签的功能，标签上显示**产品型号，等级，打印产品型号**三个信息

```java
//ftProductPrintConfigForm.js
{
		text: i18n_fld_Label_Print,
		region: 'center',
		handler: Ext.doPrintLabel
}

Ext.doPrintLabel = function(){
	var rows = Ext.getCmp("FtProductPrintConfigGrid").getSelectionModel().selected;
	if(rows.length <= 0){
		MyCim.notify.alert(i18n_msg_Please_choose_the_data_which_you_want_to_print);
		return;
	}
	var btw = "ftPrintConfig.btw";
	var productId = Ext.getCmp("productIdForm").getValue();
	var grade = Ext.getCmp("stationLevelForm").getValue();
	var printProductModel = Ext.getCmp("printProductForm").getValue();

	var finalPrintInfo = "productId=" + productId + ";grade=" + grade
		+ ";printProductModel=" + printProductModel;
	bartenderPrint(finalPrintInfo,btw,1);
}
```

需要添加一个[模板](ftPrintConfig.btw)，放置在D盘下的`D:\\btwConfig`
