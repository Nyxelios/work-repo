# 六、liquibase的使用及yaml的书写规范

维护数据库使用liquibase技术，添加yaml文件来对数据库进行添加表，修改字段等操作，禁止执行sql语句修改数据库，创建表时需要给每一列添加注释

1. 参考项目中的yaml文件来对数据库进行添加表
2. 给已存在的表添加字段，修改字段，删除表，添加约束等均使用liquibase技术，详细参考 https://docs.liquibase.com/change-types/home.html
3. 禁止使用sql语句对数据库表结构进行修改，
4. 创建表时要给每一列添加注释
5. 每个表都要有主键
6. 尽量不给表添加唯一约束，数据判断放在业务层
