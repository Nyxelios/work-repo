# 功能验收文档：工单日期验证逻辑优化

## 1. 需求背景

### 1.1 业务场景
OIS（光学图像传感器）拆包业务存在当天上线拆包、当天完工入库的需求。原系统限制工单的**预计完成时间**必须晚于明天，导致无法创建当天完工的工单，严重影响业务流程。

### 1.2 原问题描述
- **计划投入时间**：允许选择今天及以后（合理）
- **预计完成时间**：必须选择明天及以后（不合理）
- **完工时间与投入时间关系**：必须严格晚于投入时间（不合理）

### 1.3 影响范围
- 涉及文件：`WorkOrderServiceImpl.java`
- 影响模块：工单创建、工单编辑功能

## 3. 验证规则说明

### 3.1 修改前规则
| 字段 | 验证规则 |
|------|---------|
| 计划投入时间 | 必须 ≥ 今天 |
| 预计完成时间 | 必须 ≥ 明天 |
| 完工与投入关系 | 完工时间 > 投入时间（严格晚于） |

### 3.2 修改后规则
| 字段 | 验证规则 |
|------|---------|
| 计划投入时间 | 必须 ≥ 今天 |
| 预计完成时间 | 必须 ≥ 今天 |
| 完工与投入关系 | 完工时间 ≥ 投入时间（允许同一天） |

## 5. 功能验证清单

### 5.1 功能验证
- [ ] 工单创建页面可选择当天日期作为预计完成时间
- [ ] 当天投入、当天完工的工单可正常保存
- [ ] 原有日期验证逻辑（计划投入时间不能早于今天）保持有效

### 5.2 边界条件验证
- [ ] 计划投入时间 = 预计完成时间 = 今天：允许
- [ ] 计划投入时间 = 今天，预计完成时间 = 明天：允许
- [ ] 计划投入时间 > 预计完成时间：拒绝
- [ ] 计划投入时间 < 今天：拒绝
- [ ] 预计完成时间 < 今天：拒绝

### 5.3 接口验证
- [ ] `createWorkOrder` 接口支持当天完工日期
- [ ] `updateWorkOrder` 接口支持当天完工日期
- [ ] 错误消息正确（`PLAN_TIME_CAN_NOT_BE_BEFORE_THAN_TODAY`）
