# COM 增加子型号流程优化 —— 型号-IR 属性配置表

> 记录日期：2026-04-29
> 状态：需求记录（待开发）
> 本次 MES 侧仅实现"配置表"功能，工控程序后续会调取本配置表。

---

## 一、背景

![22d27fd5d9f9b2f1ea504c7ce28743a9.png](https://files-1259440452.cos.ap-nanjing.myqcloud.com/Obsidian/22d27fd5d9f9b2f1ea504c7ce28743a9.png)

COM 由于产品的特殊性，COM 产品型号在芯片相同的情况下，由于组件 & 键合线的差异存在多种子型号，导致频繁存在程序升级的需求。

然而对于程序而言，同大型号下不同子型号间测试程序差异只取决于组件 IR（白玻 & 蓝玻），程序的差异只有 Ratio 的 spec 存在差异，不同项目的开发立项导致频繁升级程序，造成工程资源的浪费。

## 二、目的

减少 COM 因频繁新增子型号导致程序升级造成的工程资源浪费（涉及部门：产品 / QA / 计划 / 生产）。

## 三、本次 MES 变更范围（本期实现）

**新增"型号-IR 属性配置表"（IR 属性配置表）**，用于维护"产品型号 → IR 属性"的映射关系。

### 3.1 配置表字段

| 字段名     | 说明                                            | 备注                  |
| ---------- | ----------------------------------------------- | --------------------- |
| 产品型号   | COM 产品的子型号，例如 GC08A8-MAMD1-4.7         | 主键                  |
| IR 属性    | 组件 IR 属性，取值如 B / W / T 等               | 下拉选择，不可手填    |

### 3.2 示例数据

| 产品型号           | IR 属性 |
| ------------------ | ------- |
| GC08A8-MAMD1-4.7   | B       |
| GC08A8-MAMD0-4.7   | B       |
| GC08A8-MADC0-4.7   | W       |
| GC08A8-MAGG0-4.7   | T       |

### 3.3 业务规则 / 校验

1. **IR 属性做下拉选择**，不允许自由输入。
2. **需做防呆**：同一个产品型号只能存在一条记录，即一个产品型号只对应一种 IR 属性（唯一性约束）。
3. 配置表入口预计挂在"产品自审配置"菜单组下（与 COM 自审、COM 入 ATE 测试配置、COM 站别测试配置、MP 测试程序配置、COM 通流控制规则等同级），最终菜单位置开发时确认。

## 四、后续工控变更（非本期实现，仅记录上下文）

> 以下由工控程序侧实现，MES 侧仅需提供上述配置表及查询接口/视图。

在现有发送信息基础上，工控会额外查询 MES 的"型号-IR 属性配置表"获取 IR 属性，并按以下规则发送给测试软件：

1. 若型号-IR 属性配置表获取成功 → 记录 `型号 & 属性` 字段，例如：`GC08A8-MAMD1-4.7-B/W/T` 发送给测试软件。
2. 若型号-IR 属性配置表获取失败 → 记录 `型号 + 指定 IR 为空` 表示字段，例如：`GC08A8-MAMD1-4.7-K` 发送给测试软件。

**过渡阶段**：由于程序无法同时间全部导入升级，在保留原功能不受影响的情况下支持 by 型号导入升级（小改动，大功能）。
